# Project Purpose

This project converts the research synopsis into a PowerPoint-style academic presentation website suitable for:

- Ph.D. Synopsis Presentation
- Research Proposal Defense
- Supervisor Review
- Departmental Presentation
- Research Scholar Preparation
- Viva Preparation
- GitHub Pages Hosting

All content is based strictly on the uploaded synopsis PDF.

No external academic content has been added.

# Deployment on GitHub Pages

## Step 1

Create a new GitHub repository.

Example:

research-synopsis-presentation

---

## Step 2

Upload:

- index.html
- style.css
- script.js
- README.md

---

## Step 3

Open Repository Settings

Settings → Pages

---

## Step 4

Under Source:

Deploy from Branch

Select:

main

and

/root

---

## Step 5

Save

GitHub will generate a Pages URL.

Example:

https://yourusername.github.io/research-synopsis-presentation/
